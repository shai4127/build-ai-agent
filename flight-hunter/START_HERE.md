# מתחילים כאן

## צעד אחד
פתח את התיקייה `flight-hunter` שעל שולחן העבודה כפרויקט ב-**Claude Code**, בשיחה חדשה. אל תעלה אותה כקובץ מצורף לצ'אט. אחר כך כתוב:

> **אני רוצה להתחיל**

## מה הסוכן יעשה אז
1. **יבדוק בלי לשנות כלום:** שיש Python, שהספריות מותקנות, שקובץ הטבלה קיים, שהגדרות ה-WhatsApp מולאו, ואם המשימות המתוזמנות כבר רשומות ב-Windows.
2. **יציג קודם את המשימות המתוזמנות**, בכרטיס כזה:

```text
לפני שמתחילים: הפעלת המשימות המתוזמנות

[READY_TO_ACTIVATE] משימה 1: כל יום 00:00 UTC (02:00 בחורף / 03:00 בקיץ שעון ישראל)
מה היא עושה: מחפשת את הטיסה הישירה הזולה ביותר TLV↔HER ל-15–21.8.2027
לאן התוצר מגיע: שורה ב-flights.xlsx, ו-WhatsApp אם המחיר ירד

[READY_TO_ACTIVATE] משימה 2: כל יום 12:00 UTC (14:00 / 15:00)
מה היא עושה: כנ"ל
לאן התוצר מגיע: כנ"ל

[READY_TO_ACTIVATE] משימה 3: כל יום 20:00 UTC (22:00 / 23:00)
מה היא עושה: כנ"ל
לאן התוצר מגיע: כנ"ל

להפעיל עכשיו, לשנות את התזמון, או להשאיר את הסוכן להפעלה ידנית?
```

3. **יציג כרטיס מוכנות:**

```text
הסוכן מוכן להגדרה

[✓/!] הוראות ופרופיל
[✓/!] מקורות וקבצים (Google Flights, Skyscanner, Kayak)
[✓/!] סקריפטים מקומיים (Python, Playwright, openpyxl)
[✓/!] WhatsApp דרך CallMeBot
[✓/!] משימות ב-Windows Task Scheduler

מה יקרה לאחר האישור:
1. התקנת הספריות החסרות (tools\setup.ps1)
2. הגדרת CallMeBot: אתה ממלא מספר ומפתח ב-.env
3. בדיקה אחת מלאה: שורה ראשונה בטבלה והודעת WhatsApp לבדיקה
4. רישום 3 המשימות היומיות ואימות מועד הריצה הבאה

פעולות שתמיד ידרשו אישור נפרד:
- שינוי תאריכים, נוסעים או מקורות
- שינוי או מחיקה של משימות מתוזמנות
(הזמנה ותשלום: הסוכן לעולם לא מבצע)

לאשר ולהפעיל?
```

4. רק אחרי שתכתוב "כן" הוא יבצע את השלבים ויראה לך מה פעיל בפועל.

## איך לוודא שהכול באמת פעיל
- **המשימות:** פתח את Task Scheduler. בתיקייה `FlightHunter` צריכות להופיע 3 משימות עם Next Run Time. אפשר גם להריץ ב-PowerShell:
  `Get-ScheduledTask -TaskPath '\FlightHunter\' | Get-ScheduledTaskInfo`
- **הטבלה:** קובץ `flights.xlsx` בתיקייה הזאת. אחרי כל בדיקה נוספת בו שורה.
- **יומנים:** בתיקייה `logs\` יש קובץ לכל ריצה, שמראה מה קרה.
- **WhatsApp:** בהפעלה הראשונה תגיע הודעת בדיקה.

## חשוב לדעת
- המחשב צריך להיות דלוק או במצב שינה, ואתה מחובר למשתמש שלך. המשימות מעירות את המחשב משינה. אם המחשב היה כבוי, הבדיקה שהוחמצה תרוץ ברגע שהוא יידלק.
- אם `flights.xlsx` פתוח ב-Excel בזמן בדיקה, השורה נשמרת בצד ונכתבת בבדיקה הבאה.
- המעקב נעצר אוטומטית אחרי 15.8.2027.
