4. רק אחרי שתכתוב "כן" הוא יבצע את השלבים ויראה לך מה פעיל בפועל.

## איך לוודא שהכול באמת פעיל
- **המשימות:** פתח את Task Scheduler. בתיקייה `FlightHunter` צריכה להופיע משימה אחת, `FlightHunter-Hourly`, עם Next Run Time בשעה העגולה הבאה. אפשר גם להריץ ב-PowerShell:
  `Get-ScheduledTask -TaskPath '\FlightHunter\' | Get-ScheduledTaskInfo`
- **הטבלה:** קובץ `flights.xlsx` בתיקייה הזאת. אחרי כל בדיקה נוספת בו שורה.
- **יומנים:** בתיקייה `logs\` יש קובץ לכל ריצה, שמראה מה קרה.
- **WhatsApp:** בהפעלה הראשונה תגיע הודעת בדיקה.

## חשוב לדעת
- המחשב צריך להיות דלוק או במצב שינה, ואתה מחובר למשתמש שלך. המשימות מעירות את המחשב משינה. אם המחשב היה כבוי, הבדיקה שהוחמצה תרוץ ברגע שהוא יידלק.
- אם `flights.xlsx` פתוח ב-Excel בזמן בדיקה, השורה נשמרת בצד ונכתבת בבדיקה הבאה.
- המעקב נעצר אוטומטית אחרי 15.8.2027.
