# זיכרון

## מה נזכר, ואיפה
| מה | איפה | הערות |
|---|---|---|
| כל המחירים שנבדקו | `flights.xlsx` | מקור האמת למחיר הקודם ולשפל |
| המחיר הזול ביותר עד עכשיו | מחושב מהטבלה (`flights_log.py status`) | לא נשמר בנפרד, כדי שלא תהיה סתירה |
| מה קרה בכל ריצה | `RUN_LOG.md` (שורה לריצה) ו-`logs\` (פירוט) | |
| פרטי הנסיעה | `tools/config.json` ו-`USER_PROFILE.md` | שינוי רק באישור הבעלים |
| לקחים | הסעיף "לקחים" בקובץ הזה | למשל "Kayak חוסם תמיד", או "בישראייר תעריף Basic לא כולל מזוודה" |

## מה לא שומרים
סודות (נמצאים ב-`.env` בלבד), פרטים אישיים של הנוסעים, ותוכן מלא של דפי אינטרנט.

## סתירות
אם יש סתירה בין `USER_PROFILE.md` לבין `tools/config.json`, **מפסיקים** ושואלים את הבעלים בשיחה הידנית הבאה. בריצה מתוזמנת משתמשים ב-`config.json` ורושמים אזהרה ביומן.

## מתי לאשר מחדש
- פעם בחודש, בשיחה ידנית: "התאריכים והנוסעים עדיין נכונים?"
- כשמקור חסום 3 ריצות ברצף.
