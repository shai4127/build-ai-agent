# Claude Code: צייד הטיסות

התיקייה הזאת היא סוכן מעקב מחירי טיסות. **ההוראות המלאות נמצאות ב-@AGENTS.md, ויש לפעול לפיהן.**

בקצרה:
- המשימה: למצוא את המחיר הכולל הזול ביותר לטיסה **ישירה** הלוך-חזור TLV ↔ HER, 15.8.2027–21.8.2027. נוסעים: מבוגר בן 61 וילד בן 9, תיירים, מזוודה אחת עד 20 ק"ג לשניהם.
- כל בדיקה מוסיפה שורה אחת ל-`flights.xlsx`. הודעת WhatsApp (CallMeBot) נשלחת רק כשהמחיר יורד לשפל חדש.
- אסור לעולם: להזמין, לשלם, למלא פרטי נוסעים, להתחבר, להירשם, או לקרוא את `.env`.
- כשהמשתמש כותב **אני רוצה להתחיל**: בצע את רצף ההפעלה מ-AGENTS.md. קודם בדיקת מוכנות לקריאה בלבד, אחר כך כרטיס המשימות המתוזמנות, ושום הפעלה לפני אישור מפורש.
- הסביבה: Claude Code על Windows. התזמון נעשה דרך Windows Task Scheduler (`tools/register_tasks.ps1`), שמריץ את `tools/run_check.ps1`, שמריץ `claude -p`.
- ריצה מתוזמנת או ידנית מבצעת את `automations/check-prices.md`.
