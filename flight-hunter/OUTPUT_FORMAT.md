# פורמט התוצרים

## 1. טבלת Excel: התוצר הראשי
- **קובץ:** `flights.xlsx` בתיקיית הסוכן, על המחשב של הבעלים.
- **לשונית:** "כל הבדיקות" (מימין לשמאל, עם כותרת קבועה).
- **קהל:** הבעלים. הטבלה נועדה לסריקה מהירה של מגמת המחיר.
- **כלל:** **בכל בדיקה נוספת שורה אחת**, עם הטיסה הישירה הזולה ביותר מכל המקורות באותה בדיקה. השורות מסודרות לפי זמן, והחדשה ביותר למטה.

| עמודה | תוכן | חובה |
|---|---|---|
| תאריך בדיקה | DD/MM/YYYY (נקבע אוטומטית) | ✓ |
| שעת בדיקה (שעון ישראל) | HH:MM (נקבע אוטומטית) | ✓ |
| זמן גריניץ' | HH:MM לפי UTC/GMT (נקבע אוטומטית) | ✓ |
| אתר | האתר שבו נמצאה ההצעה הזולה | ✓ אם נמצא |
| חברת תעופה | למשל ישראייר | ✓ אם נמצא |
| מס' טיסה הלוך | למשל 6H 507 | אם מוצג |
| המראה/נחיתה הלוך | למשל 06:10 → 08:25 | ✓ אם נמצא |
| מס' טיסה חזור | | אם מוצג |
| המראה/נחיתה חזור | | ✓ אם נמצא |
| מחיר בסיס (₪) | המחיר לשניים לפני תוספת מזוודה | ✓ אם נמצא |
| שער הדולר (₪ ל-1$) | שער יציג של בנק ישראל בזמן הבדיקה (נקבע אוטומטית; גיבוי: Frankfurter/ECB). אם אין, נשאר ריק ונכתב בהערות | אוטומטי |
| תוספת מזוודה (₪) | 0 אם כלולה; ריק אם לא ידוע | |
| **מחיר כולל לשניים (₪)** | בסיס + מזוודה | ✓ אם נמצא |
| שינוי מהבדיקה הקודמת (₪) | מחושב אוטומטית (שלילי פירושו ירידה) | אוטומטי |
| קישור | קישור לחיפוש או להצעה (ניתן ללחיצה) | ✓ אם נמצא |
| הערות | אילו אתרים נבדקו או נחסמו, מצב המזוודה, המרות, "לא נמצא" וסיבה | ✓ |

**כשאין תוצאה:** נרשמת שורה שבה עמודות המחיר ריקות, ובהערות כתוב "לא נמצא" וסיבה. דוגמה: "לא נמצא. התאריכים עוד לא פתוחים למכירה."

**דוגמת שורה:**
`05/11/2026 | 14:00 | 12:00 | Google Flights | ישראייר | 6H 507 | 06:10→08:25 | 6H 508 | 09:25→11:40 | 2,780 | 3.752 | 0 | 2,780 | -120 | https://… | נבדק: Google Flights. מזוודה 20 ק"ג כלולה בתעריף.`

**טבלה קיימת בפורמט הישן** (בלי שתי העמודות החדשות) משודרגת אוטומטית בפעם הבאה שהסקריפט נוגע בה. העמודות מותאמות לפי שם, זמן גריניץ' מחושב מהתאריך ומשעת ישראל, ושער הדולר בשורות הישנות נשאר ריק כי הוא לא נרשם אז. גם טבלה שנערכה ידנית מותאמת: עמודות מזוהות לפי שם, גם כשהכתיב שונה (למשל "זמן גריניצ" או "שער דולר"). עמודות שהבעלים הוסיף בעצמו נשמרות בסוף הטבלה, ולשוניות אחרות לא משתנות. לפני השדרוג נשמר עותק בשם `flights_backup_<תאריך>.xlsx`.

## 2. הודעת WhatsApp על ירידה
**נשלחת רק כאשר:** המחיר הכולל נמוך מכל מחיר קודם בטבלה (`new_low`), או בפעם הראשונה שנמצא מחיר בכלל (`first_price`). בכל מקרה אחר לא נשלחת הודעה.
**יעד:** הצ'אט של הבעלים עם עצמו, דרך WhatsApp Web בדפדפן המקומי (`tools/notify_whatsapp.py`) בלבד.

**פורמט, בירידה:**
```
✈️ צייד הטיסות: מחיר נמוך חדש!
תל אביב ⇄ הרקליון | 15–21.8.2027 | ישירה
💰 ₪2,780 לשניים (היה ₪2,900, ירידה של ₪120)
🛫 ישראייר 06:10→08:25 | 🛬 09:25→11:40
🧳 מזוודה 20 ק"ג: כלולה
🔗 https://…
```

**פורמט, מחיר ראשון:** אותו מבנה, עם הכותרת "✈️ צייד הטיסות: נמצא מחיר ראשון" ובלי שורת "היה".

**אסור להשמיט:** מחיר כולל, מצב המזוודה, קישור.

## 3. סיכום בוקר ב-WhatsApp: כל יום
**מתי:** פעם ביום, אחרי הבדיקה של 08:00 שעון ישראל. אם הבדיקה הזאת דולגה, למשל כי המחשב היה כבוי, הסיכום יוצא בבדיקה הראשונה שאחריה. ההודעה נבנית אוטומטית (`flights_log.py daily-summary`), ונשלחת כמו שהיא.
**תוכן:** 3 המחירים הזולים ביותר מתוך 24 השורות האחרונות בטבלה. הצעה זהה (אותו מחיר, אותה חברה ואותן טיסות) שחוזרת בכמה בדיקות מופיעה פעם אחת, עם זמן הבדיקה האחרון שבו נראתה.

```

תל אביב ⇄ הרקליון | 15–21.8.2027 | ישירה
3 המחירים הזולים מ-24 הבדיקות האחרונות (04/11/2026 09:00 עד 05/11/2026 08:00):

1. 💰 ₪2,780 לשניים | ישראייר
   🛫 6H 507 06:10→08:25 / 6H 508 09:25→11:40
   🔎 Google Flights | נבדק 05/11/2026 03:00 (ישראל) / 01:00 GMT
   🔗 https://…

2. …
3. …

ב-5 מתוך 24 בדיקות לא נמצא מחיר.
```

**כשאין מחירים:** נשלחת הודעה עם הכותרת, ומתחתיה "לא נמצא מחיר באף אחת מהבדיקות האלה".
