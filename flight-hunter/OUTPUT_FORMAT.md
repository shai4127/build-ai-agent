# פורמט התוצרים

## 1. טבלת Excel: התוצר הראשי
- **קובץ:** `flights.xlsx` בתיקיית הסוכן, על המחשב של הבעלים.
- **לשונית:** "כל הבדיקות" (מימין לשמאל, עם כותרת קבועה).
- **קהל:** הבעלים. הטבלה נועדה לסריקה מהירה של מגמת המחיר.
- **כלל:** **בכל בדיקה נוספת שורה אחת**, עם הטיסה הישירה הזולה ביותר מכל המקורות באותה בדיקה. השורות מסודרות לפי זמן, והחדשה ביותר למטה.

| עמודה | תוכן | חובה |
|---|---|---|
| תאריך בדיקה | DD/MM/YYYY (נקבע אוטומטית) | ✓ |
| שעת בדיקה (שעון ישראל) | HH:MM (נקבע אוטומטית) | ✓ |
| אתר | האתר שבו נמצאה ההצעה הזולה | ✓ אם נמצא |
| חברת תעופה | למשל ישראייר | ✓ אם נמצא |
| מס' טיסה הלוך | למשל 6H 507 | אם מוצג |
| המראה/נחיתה הלוך | למשל 06:10 → 08:25 | ✓ אם נמצא |
| מס' טיסה חזור | | אם מוצג |
| המראה/נחיתה חזור | | ✓ אם נמצא |
| מחיר בסיס (₪) | המחיר לשניים לפני תוספת מזוודה | ✓ אם נמצא |
| תוספת מזוודה (₪) | 0 אם כלולה; ריק אם לא ידוע | |
| **מחיר כולל לשניים (₪)** | בסיס + מזוודה | ✓ אם נמצא |
| שינוי מהבדיקה הקודמת (₪) | מחושב אוטומטית (שלילי פירושו ירידה) | אוטומטי |
| קישור | קישור לחיפוש או להצעה (ניתן ללחיצה) | ✓ אם נמצא |
| הערות | אילו אתרים נבדקו או נחסמו, מצב המזוודה, המרות, "לא נמצא" וסיבה | ✓ |

**כשאין תוצאה:** נרשמת שורה שבה עמודות המחיר ריקות, ובהערות כתוב "לא נמצא" וסיבה. דוגמה: "לא נמצא. התאריכים עוד לא פתוחים למכירה; Skyscanner חסום."

**דוגמת שורה:**
`26/10/2026 | 14:00 | Google Flights | ישראייר | 6H 507 | 06:10→08:25 | 6H 508 | 09:25→11:40 | 2,780 | 0 | 2,780 | -120 | https://… | נבדקו: Google Flights, Kayak. Skyscanner חסום. מזוודה 20 ק"ג כלולה בתעריף.`

## 2. הודעת WhatsApp: רק בירידה
**נשלחת רק כאשר:** המחיר הכולל נמוך מכל מחיר קודם בטבלה (`new_low`), או בפעם הראשונה שנמצא מחיר בכלל (`first_price`). בכל מקרה אחר לא נשלחת הודעה.
**יעד:** המספר של הבעלים דרך CallMeBot בלבד.

**פורמט, בירידה:**
```
✈️ צייד הטיסות: מחיר נמוך חדש!
תל אביב ⇄ הרקליון | 15–21.8.2027 | ישירה
💰 ₪2,780 לשניים (היה ₪2,900, ירידה של ₪120)
🛫 ישראייר 06:10→08:25 | 🛬 09:25→11:40
🧳 מזוודה 20 ק"ג: כלולה
🔗 https://…
```

**פורמט, מחיר ראשון:** אותו מבנה, עם הכותרת "✈️ צייד הטיסות: נמצא מחיר ראשון" ובלי שורת "היה".

**אסור להשמיט:** מחיר כולל, מצב המזוודה, קישור.
